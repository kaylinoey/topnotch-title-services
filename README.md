# Topnotch Title Services Inc. Website

This folder contains the finished static website.

## Uploading through GitHub.com

1. Open your `topnotch-title-services` repository.
2. Choose **uploading an existing file** under **Quick setup**.
3. Drag all files and folders from this folder into GitHub's upload area.
4. Enter `Add Topnotch website` as the commit message.
5. Select **Commit changes**.

The website includes Residential, Commercial, and Closing Services; an informational title-insurance calculator; an in-person closing guide; and Parsippany, New Jersey contact information.
