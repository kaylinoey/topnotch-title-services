# Upload these files to GitHub

This package is configured specifically for:

`https://kaylinoey.github.io/topnotch-title-services/`

1. Open the `topnotch-title-services` repository on GitHub.
2. Delete or replace the previously uploaded website files.
3. Choose **Add file → Upload files**.
4. Upload everything inside this folder, including `.nojekyll` and the `_next` folder.
5. Commit the changes to the `main` branch.
6. Keep GitHub Pages configured for `main` and `/ (root)`.

Do not add a Jekyll theme.
